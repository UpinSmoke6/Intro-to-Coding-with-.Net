# Intro to Coding with .NET

This repository contains my C# coursework and practice projects
as I learn programming with Visual Studio at Riverland Community College.

## What I'm Learning

- Variables and data types
- User input and type conversion
- If/else statements and switch statements
- For, foreach, and while loops
- Arrays
- Methods and parameters
- Windows Forms controls and button events
- Input validation and error handling

## Projects

- **GuessGame:** Guess a random number and receive feedback.
- **FlashCards:** Practice randomly generated addition and subtraction problems.
- **SimpleCalculator:** Practice calculations using a Windows Forms interface.
- **VariablesApp:** Explore converting text into different data types.
- **MadLibApp:** Build a story using user input.
- **Other exercises:** Practice arrays, loops, methods, and conditionals.

## Running the Projects

1. Download or clone this repository.
2. Open the project you want to try in Visual Studio.
3. Build and run the project using the Start button.

Windows Forms projects require Windows.
